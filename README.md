
# 🕹️ Neon Taş Kağıt Makas Oyunu

Klasik "Taş-Kağıt-Makas" oyununu neon temalı modern bir arayüzle sunan bu proje, HTML, Tailwind CSS ve GSAP kullanılarak geliştirilmiştir. Bilgisayara karşı oynanabilir, skor takibi yapılır ve sonuçlar animasyonlarla gösterilir.

---

## 🎯 Oyun Özellikleri

- 🎮 **Oyuncu vs Bilgisayar**: Bilgisayar rastgele seçim yapar.
- ✨ **Neon Temalı Tasarım**: Parlak sınırlar ve animasyonlu düğmeler.
- 🎨 **Tailwind CSS**: Hızlı ve mobil uyumlu stil kullanımı.
- 💥 **GSAP Animasyonları**: Başlık, buton ve skor efektleri.
- 🎯 **Skor Takibi**: Canlı olarak güncellenen skor panosu.
- 🔁 **Oyun Sıfırlama**: Tek tuşla sıfırlama seçeneği.
- 📣 **Sonuç Bildirimi**: Kazanma, kaybetme, berabere animasyonlu metinlerle.

---

## 🛠️ Kullanılan Teknolojiler

- HTML5  
- Tailwind CSS  
- JavaScript (Vanilla)  
- GSAP (GreenSock)
